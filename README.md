# بوت تلجرام لقصص الغموض والرعب

## الملفات
- `main.py`: كود البوت والجدولة.
- `requirements.txt`: المكتبات المطلوبة.
- `render.yaml`: إعداد عامل سحابي على Render.
- `stories.json`: ملف اختياري لتوثيق القصص وتحريرها؛ القصص المستخدمة حاليًا موجودة داخل `main.py`.

## 1) إنشاء البوت من BotFather
1. افتح Telegram وابحث عن `@BotFather` الرسمي.
2. أرسل `/newbot`.
3. اختر اسمًا للبوت ثم username ينتهي بـ `bot`.
4. انسخ التوكن. لا تشاركه مع أحد ولا تضعه داخل الكود أو GitHub.

## 2) إضافته للجروب
1. أضف البوت إلى الجروب.
2. تأكد أنه مسموح له بإرسال الرسائل. غالبًا لا يحتاج صلاحية مشرف لمجرد إرسال الرسائل، لكن إعدادات الجروب قد تختلف.
3. أرسل `/id` داخل الجروب. انسخ رقم المحادثة الذي يظهر. غالبًا يبدأ رقم الجروب السوبر بـ `-100`.
4. لو لم يرد على الأوامر، افتح `@BotFather` ثم `/setprivacy` واختر البوت و`Disable` عند الحاجة، وبعدها أعد إضافته للجروب. للأوامر مثل `/id` غالبًا لا يلزم تعطيل Privacy Mode.

## 3) النشر على Render
1. ارفع ملفات المشروع إلى مستودع GitHub خاص.
2. أنشئ حسابًا في Render وافتح لوحة التحكم.
3. اختر New > Blueprint، ثم اربط مستودع GitHub الذي يحتوي على `render.yaml`.
4. أضف القيم السرية المطلوبة:
   - `BOT_TOKEN`: التوكن الذي أعطاك BotFather.
   - `CHAT_ID`: رقم الجروب الذي حصلت عليه من `/id`.
5. تأكد من `TIMEZONE=Asia/Amman` و`SCHEDULE_TIMES=09:00,15:00,21:00`.
6. انشر الخدمة كـ Background Worker، وتأكد أن الخطة المختارة تدعم عاملًا دائمًا. قد تتطلب الاستضافة الدائمة خطة مدفوعة حسب عروض المنصة الحالية.

## 4) تشغيل محلي للاختبار
Python 3.11 أو أحدث:
```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```
اضبط متغيرات البيئة قبل التشغيل. مثال macOS/Linux:
```bash
export BOT_TOKEN="ضع_التوكن_هنا"
export CHAT_ID="-1001234567890"
export TIMEZONE="Asia/Amman"
export SCHEDULE_TIMES="09:00,15:00,21:00"
python main.py
```
على Windows PowerShell:
```powershell
$env:BOT_TOKEN="ضع_التوكن_هنا"
$env:CHAT_ID="-1001234567890"
$env:TIMEZONE="Asia/Amman"
$env:SCHEDULE_TIMES="09:00,15:00,21:00"
python main.py
```

## 5) تغيير مواعيد النشر
عدّل `SCHEDULE_TIMES` في إعدادات الاستضافة، مثل:
`08:30,14:00,20:30`
استخدم نظام 24 ساعة. الأوقات حسب `TIMEZONE`.

## ملاحظات مهمة
- لا ترفع التوكن إلى GitHub، حتى لو كان المستودع خاصًا.
- لو ظهر التوكن في مكان عام، ألغِه فورًا من BotFather وولّد توكنًا جديدًا.
- في النسخة الحالية، القصص مكتوبة داخل `main.py` لتبسيط التشغيل. أضف قصصًا جديدة داخل قائمة `STORIES`.
- اختيار القصة يعتمد على اليوم وموعد النشر؛ هذا يمنع التكرار داخل اليوم، لكنه ليس سجلًا دائمًا ضد التكرار بعد دورة القصص.
- لو أردت ضمان عدم التكرار حتى بعد إعادة النشر أو إعادة تشغيل الخدمة، استخدم قاعدة بيانات دائمة أو قرصًا دائمًا.
- لا تعتمد على ملفات محلية في عامل سحابي إذا كانت الخطة لا تضمن حفظها بعد إعادة النشر.
